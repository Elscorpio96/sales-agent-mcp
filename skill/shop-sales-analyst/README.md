# shop-sales-analyst (agent skill)

An agent skill that teaches Claude Code, Claude Desktop, Cursor, Copilot and other agents to act as a sales analyst for
a small shop, using the read-only tools of the [sales-agent MCP server](https://github.com/Elscorpio96/sales-agent-mcp).

- `SKILL.md` — when to use the tools, which tool answers which question, rules (no invented numbers, drafts are never
  sent, read-only, privacy) and the answer format.
- `references/setup.md` — install, load demo or real data, connect to each agent.
- `references/csv-format.md` and `templates/` — load the shop's own POS or spreadsheet exports.
- `references/tools.md` — parameter reference. `references/playbooks.md` — weekly review, restock list, debt follow-up
  (English and Hausa reminders), margin check.
